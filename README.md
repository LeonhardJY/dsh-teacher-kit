# 教师助手（DSH 插件）

给中国大陆中学老师用的**重复性文件工作**小工具。它只做「把文件做出来」这一段，不替老师设计教学，
也不碰学生评价、成绩分析、评语这类和人打交道的活。

装好以后，对话输入框下方会多一个「教师助手」按钮，点一下弹出这几件活：

| 卡片 | 做什么 | 产出 |
| --- | --- | --- |
| **出试卷** | 粘贴题干 →（可选）套学校空白模板 → 8 开两栏排版 → 答题卡 → 答案卷 → 印前检查；可一次出 A/B 两套、再加一份教师卷（A/B 与教师卷能一起勾，最多一次出四份） | `.docx` + `.pdf` |
| **题库组卷** | 直接选 Excel / Word 题库文件 → 出卷，不用复制粘贴 | `.docx` + `.pdf` |
| **听写单** | 单词表 → 双栏听写纸（可附答案页） | `.docx` + `.pdf` |
| **教案** | 按学校格式排成表格式 / 流程版教案 | `.docx` + `.pdf` |
| **做课件** | 粘贴这节课的内容 →（可选）套学校 PPT 模板 → 自动分页 → 「讲：」那几行进备注；也能出网页版课件 | `.pptx` / `.html` |
| **整套** | 一节课四件套：填了哪几栏就出哪几件（试卷 / 听写单 / 教案 / 课件），哪件没做成只报那一件 | 各自格式 |
| **文件加工** | 净化 Word（拆超链接、去彩色、统一字体、清空段、清批注）· 批量净化 · 合并多份 · 提取文字 · 检查一份卷子 | `.docx` / 文字 |
| **公众号推文** | 学校活动宣传稿：标题 → 摘要 → 分段正文 → 可粘贴的排版（不联网、不发布） | `.html` + `.docx` |
| **公文流转** | 上级来文 → 收文登记 → 来文要点 → 拟办意见 → 领导批示 → 承办流转单 → 回复稿 | `.docx` |
| **模板** | 把上学期那份卷子变成下学期能用的空白模板（在面板底部「老方式」里） | `.docx` |

纯本地：不联网、不上传、不收集任何东西。用的是 DSH 自带的 Python 与内置 LibreOffice，
**不需要另外装 Office**；做出来的 Word/PPT 在 WPS 里照常打开。

### 两条路，选一条

- **对话式（推荐，0.15 起默认）**：点「教师助手」→ 点一件事（比如「出试卷」）→ 面板关掉，
  下面的话框里出现一句“我想做这件事”，**接着就在对话里说**。它会先问你这次考哪个单元、
  要不要用学校模板、成品要哪几种；缺材料会点名跟你要，问清了就直接做，做完把文件路径和预览给你。
- **老方式（填表就出）**：面板底部「直接出成品（老方式：填表就出，不经过对话）」。
  表单填完点「开始做」，一个来回出结果卡。熟了可以用它快点出东西。

两条路用的是同一套引擎、同一套排版，产物完全一样。第一次用建议走对话式——
它会顺手把你们学校的规矩记下来（见 [十二、学校画像](#十二学校画像越用越像你们学校)）。

## 一、安装

要求：Windows 上的 DeepSeek Harness（桌面版或 `dsh web`），版本 `>= 0.2.1-rc.2`。

### 办法 A：插件市场（发布后）

设置 → **插件市场** → 搜「教师助手」→ 安装 → 刷新页面。

### 办法 B：本地安装（现在）

拿到 `dist/` 里版本号最大的那个包（当前 `dsh-teacher-kit-0.18.0.zip`）后：

1. 解压到任意目录，比如 `D:\教师助手插件\teacher-kit`。
2. 在这个目录里打开命令行，执行：

   ```sh
   node scripts/install-local.mjs --profile desktop
   ```

   （用 `dsh web` 的改成 `--profile web`；脚本会把插件复制进该 profile 的
   `node_modules`，并在 `cordis.patch.yml` 里加一条启用记录。加 `--dry-run` 只打印准备做什么，
   加 `--uninstall` 卸掉。）
3. **重启 DSH**（关掉窗口再打开），打开任意对话，输入框下方应出现「教师助手」。

装好后可以随时验证：设置 → 插件市场 → 已安装，能看到 `dsh-teacher-kit`；
或者在对话里让助手调用 `teacher_kit_status`，它应该回 Python 与 LibreOffice 的版本。

## 二、出试卷

1. 点「教师助手」→「出试卷」。
2. 填不填都行：**卷子名称**、**学校模板路径**、**考试时长**、**纸型 / 版式**。
   - 纸型 / 版式默认 **8 开横向两栏**（大型考试最常用）；单元小测可以选 **16 开一栏**、只打印几张就选 **A4 一栏**，
     语文/数学那种大卷可以选 **A3 横向两栏**。题库组卷那张卡也有同样的下拉。
   - 学校模板 = 你们学校那份空白卷子（`.docx`）。路径可以直接从资源管理器地址栏复制。
     选了模板时**模板的纸型优先**（下拉只是没模板时的默认值）。
     模板里的页眉（学年、学校）、页脚（第 X 页 共 Y 页、使用班级、出卷老师）会保留，
     正文清空后重新排。
3. 把题干**粘贴**进大框（手上有现成的 Word 卷子也可以点题干框上方的「从 Word 卷子里读题干」，
   选文件后正文自动填进来，标题空着会取正文第一行）。格式认得这些：

   ```
   一、听力（20 分）
   1. What does the boy want to buy?
   A. A book  B. A pen  C. A bag  D. A cup
   2. 下列字音正确的是（ ）
   A. zhān  B. zhǎn  C. zhàn  D. zhàn
   【答案】B
   【解析】zhǎn 是上声。
   ```

   - 大题：`一、` `二、`（或「第一部分」「Ⅰ.」）；括号里的分值会读进来。
   - 小题：`1.` `1、` `2)`；小题号可以跨大题连续，也可以每个大题从 1 开始。
   - 选项：`A. B. C. D.` 一行多个或一行一个都行。
   - 答案/解析：`【答案】`、`【解析】`（或「答案：」「解析：」）；勾「附参考答案」才会单独成页。
   - **答案集中在卷尾也行**：粘贴时最后单独一段 `【答案】1—5 BCBDA 6—10 ABABB`（或 `1. A` 一行一条），
     我会把它当答案区收走——学生卷不会印到这一段，答案按题号回填到答案页。
     收下了几条会在结果里说明（「卷尾那段【答案】我当成答案区了（认出 N 条）」）。
4. 「使用班级」「出卷老师」两格**填了就印在每一页页脚**（七(3)班、王老师）；
   不填就留手写横线，印出来老师自己签。这两格会被记住，下次不用重填。
   勾「附答题卡（A4）」需要答题卡时勾上（题号格自动按题目数量生成，A4 竖版单栏）。
    答题卡上选择题只有「题号 + 答案」两行格；**填空 / 简答 / 翻译 / 用所给词填空**那些大题会自动留作答区，
    右边一格留多高由「填空题留几行」定（两行写单词短语 / 三行写句子 / 四行简答翻译），题号从选择题后面接着数。
   勾「附参考答案」会把答案单独排一页（老师卷口径：题号 + 答案 + 题干摘要 + 解析）。
   勾「出 A/B 两套」会一次出两份：B 卷的选项顺序打乱、答案字母跟着改，题号与分值不变。
   勾「另出一份教师卷」会一次出两份：学生卷照旧，教师卷把「【答案】」「【解析】」直接印在每道题下面
   （讲评时不用翻页找答案）；两份的文件名一个带「（学生卷）」、一个带「（教师卷）」，在同一分钟里生成。
   教师卷不印「班级/姓名/学号」那行——自己讲评用，占了首行也空着。
   两个都勾也行：A 卷、B 卷、A 卷教师、B 卷教师，一次出四份（结果卡上四个「打开…所在文件夹」）。
   作文/书面表达那一大题，答题卡上会自动留 12 行作答格（不再是只有标题没有格）。
   一份文件里同时有 8 开卷子和 A4 答题卡时，页脚只印「第 N 页」不印总页数——
   两种纸型的页数加在一起对谁都不对（8 开 6 张会被写成「共 8 页」）。
5. 要听力音频的话，在「听力录音稿」框里**一行一句**贴上去（中英混排也行，英文用英文语音、中文用中文语音），
   勾「把听力录音稿念成音频（wav，上课播放）」。出卷时会顺手念一个 `.wav`（Windows 自带的语音，离线、不用装东西），
   结果卡上写「听力音频：29 秒，4 句」并给一个「打开「听力音频（wav）」所在文件夹」。
   旁边「整段念几遍」默认念一遍；考试那种「放两遍、中间留作答时间」选 **念两遍**（中间停 4 秒），
   一个音频文件从头放到尾就是完整听力流程，不用老师手动倒回去再点一次。
   念不出来（机器没装语音包）只会提醒一句，不拦卷子——录音稿还在，可以自己读。
6. 点「出卷并导出 PDF」。

排出来的样子（不填模板时）：**标题、分值说明、班级姓名学号行跨整页**，正文从下面开始分两栏；
一道题的题干和它的 A/B/C/D 不会被栏缝或分页切开（切开了学生容易把选项算到别的题头上）。

**印前检查**会替你把这几类问题挡住（有问题就不让导 PDF，Word 照样给你，改完再点一次）：

- 纸型/方向：8 开、A3 必须横排；宽纸不许单栏。
- 页边距：与标准差超过 1mm 就提醒。
- 页脚：必须是**真页码域**（手打「第 1 页」打印机不会跟着变）；缺总页数/班级/老师会提醒。
- 题号：重复、跳号（每个大题从 1 重新开始不算跳号）。
- 分值：小题分值合计与卷面「满分 X 分」对不上会提醒。
- 字体：宋体/黑体/楷体/仿宋/微软雅黑之外的字体提醒（打印店可能没有）。
- 残留占位符：`{{examTitle}}` 这种没被替换掉会拦下来。

结果卡上是「共 N 题，合计 X 分」、每个大题的小计、用了多少秒，以及每份文件的「打开所在文件夹」。

**记住上次设置**：纸型、时长、学校模板、听写栏数、教案版式这些「选择类」的选项会记在本机，
下次打开自动带出来；题干、词表、路径、勾选框（答题卡/答案/A-B/教师卷）不会被记住——
免得下次莫名多出一页答案、或者把上一位班的题干带过来。

## 三、题库组卷

手上有现成题库（学科网、同事整理的 Excel、Word 里的一张表）时不用再复制粘贴：

1. 「教师助手」→「题库组卷」→ 点「浏览…」选题库文件（`.xlsx` / `.xls` / `.csv` / `.docx`）。
2. 表头认这些列（顺序随意、名字差不多就行）：**题号、题型、材料、题干、选项A/B/C/D、答案、解析、分值**。
   没有表头的老题库按「题号、题干、A、B、C、D、答案、解析、分值」兜底读。
   **阅读/完形的短文放「材料」（或「短文」「篇章」）那一列**：会排在这一组题目前面，连着几题同一篇只印一遍；
   忘了填也不会闷着——结果里会说「第 1、2 题是阅读/完形，但题库里没有材料（短文），学生看不到文章」。
3. 先点「看看题库里有什么」：会当场读出「题库里一共 5 题：单项选择 4 题（每题 2 分） · 填空 1 题（每题 2 分）」，不弹卡、不打断。
4. 想挑题就在「挑题」里一行写一种题型：`单项选择 10`、`完形填空 1`、`阅读理解 2`；**不填就用题库里全部**。
   挑不满只提醒不拦（题库只有 8 道单选、你要 10 道 → 就给 8 道并告诉你），题型写错会直接说「题库里没有「作文」这种题型，能挑的是：…」。
5. 填卷子名称、时长、使用班级/出卷老师，勾答题卡/参考答案 → 「组卷并导出 PDF」。
   题库组的卷子也能**套学校模板**（「套学校模板」那一格点「浏览…」选那份空白卷子）；
   选了模板就按模板自己的纸型与栏数排，不再按上面的默认 8 开硬盖。
   也能勾「出 A/B 两套」（B 卷选项打乱、答案跟着改）和「另出一份教师卷」（答案与解析印在每题下面），
   两个一起勾就是四份（A 卷 / B 卷 / A 卷教师 / B 卷教师）——题库里的题不用再复制粘贴一遍。
6. **同一批题出好几套**：在「分成几套」里选 2 / 3 / 4，会把挑中的题按题型均匀分（每套单选几道、阅读几道都差不多），
   一次落 2–4 份卷子，每份自带答案页、各自导 PDF（结果卡上写「· 第 1 套：4 题 6 分（检查通过）」）。
   适合一个单元讲完，两个班、两次随堂练各用一套。

读进来几题、识别成什么格式、哪里没读好，结果卡上都会写（挑题时写「按题型挑出 3 题（题库里一共 5 题），合计 6 分」，
不挑时写「从题库读进 5 题（xlsx），组卷 5 题，合计 10 分」）。
合并单元格里那种「A. x B. y C. z」写成一行也能拆开。

## 四、听写单

1. 「教师助手」→「听写单」→ 标题。
2. 模式：**英→中**（给英文写中文）、**中→英**（给中文写英文）、**混排**。
3. 单词表两种给法：
   - **直接选文件**（省事）：点「浏览…」选班级交上来的 `.docx` / `.xlsx` / `.csv` / `.txt`——
     Word 里的两列表格、Excel 的「英文 / 中文」两列、CSV 都读得出来，表头行（英文、中文、序号…）自动跳过，
     「Unit 4 单词表」这种整行标题也不会当成第 1 个词条。
   - **粘贴**：一行一条；`tall 高的` 这种「词 + 释义」写法认得，只写 `tall` 也行。
   首行如果是标题（「Unit 2 词汇听写」）会自动跳过，不会当成第 1 个词条。
4. 分几栏（默认 2 栏）、要不要附参考答案页 → 「出听写单并导出 PDF」。

每条排成「1. word ______」的填空样式，A4 竖版、按栏自然分列（不是表格，双栏不会被压窄）。

### 顺手念一段听写音频（不用自己读）

勾上「同时生成听写音频」，选「每条停几秒」（4 秒写得快 / 6 秒常规 / 8–10 秒词组句子）和「念几遍」，
出单子的时候会同时生成一个 `.wav`（和卷子落在同一个「听写」文件夹里，结果卡上也有「打开「听写音频（wav）」所在文件夹」）。

- 读的是：**第 1 题 … tall … tall …**（中文条目用中文语音报「第 N 题」，英文条目用英文念「Number one」），每条之间留你选的那几秒，开头留 3 秒、结尾留 2 秒。
- 用的是 Windows 自带的语音（本机实测中文「Microsoft Huihui」、英文「Microsoft Zira」），**不需要联网、不用装任何东西**。
- 双击就能用系统播放器放，投到教室音箱即可；实测 4 条词 44 秒约 1.9MB，一节课的听写一般 30–60 秒，2–3MB。
- 哪个语音没装会明确告诉你缺哪个，卷子照样出（音频那一步失败不拦交付）。

## 五、教案

1. 「教师助手」→「教案」→ 课题 / 授课教师 / 班级 / 课时。
2. 版式：**表格式**（学校最常见的表格教案）或**流程版**（纯段落）。
3. 粘贴教案草稿，字段名照你平时写的写就行：`教学目标` `重点` `难点` `学情分析` `教学过程`
   `板书设计` `作业` `教学反思`（中英文冒号、【】、一、都认；认不出的行会归到教学过程里并提示）。
   教学过程里能认出「导入 / 新授 / 操练 / 小结」这类环节，表格式会排成「环节 | 教师活动 | 学生活动 | 时间」四列。
4. 抬头表是 3 行：课题独占一行，第 2 行「课型 | 课时」，第 3 行「授课教师 | 班级」，跟学校那些表格教案一样。
5. 「学生活动」「时间」你不写就留空，表头会标成「学生活动（老师自填）」并在表下说明一句 —— 它不会替你编学生的反应。
   想让它填，就在草稿里按环节写清学生做什么。

## 六、模板

「把上学期那份卷子变成下学期能用的空白模板」：

1. 「教师助手」→「模板」→ 选上学期做好的那份卷子（`.docx`）。
2. 输出路径可以不填（默认落在 `文档\教师助手` 下）。
3. 它会读出**纸型、方向、栏数、页边距、正文字号、题号样式、页眉页脚**，把页眉页脚里的学年/页码换成
   占位符（`{{schoolYear}}`、`{{page}}`、`{{pages}}`），正文题目清空，只留标题行和说明行。
   原卷上的「满分 X 分」「时间 X 分钟」会被读出来当默认值（不再一律猜 100 分 / 90 分钟）。

以后出卷时，在「出试卷」的「学校模板」里选这份文件，就是学校自己的版式了。

模板会**把原卷的页眉页脚一起带走**（学校抬头、页码都在），班和老师留的是占位符：
出卷时在「使用班级」「出卷老师」两个格子里填上，页脚就印「七(3)班 / 王老师」；
不填就留横线。模板本身的纸型（8 开两栏 / 16 开一栏…）优先于「纸型 / 版式」那个下拉；
两边对不上时会提醒你一句，成品按你这次选的下拉走。

## 七、做课件

1. 「教师助手」→「做课件」。
2. 课题 + 学校 PPT 模板（可不填，不填就是 16:9 默认版式）。
3. 粘贴内容，用这些标记分页：

   ```
   【学习目标】
   1. 掌握 5 个核心词汇。
   2. 能用 What does he look like? 询问外貌。
   【词汇操练】
   - tall / short / thin
   - curly / straight hair
   讲：先带读两遍，再让学生描述同桌。
   ```

   - 分页标题：`【】`、markdown 的 `#`、`一、二、`，或短行 `1. xxx`。
   - 一页放不下会自动分页并标注「（续）」；拆的时候按内容**均分**（7 条拆成 4+3 或 5+2，
     不会出现「6 条挤一页、最后 1 条孤零零占一页」）。
   - `讲：` `讲稿：` `备注：` 开头的行进**备注**（放映时只有你看得见）。
   - 用模板时，模板里的旧幻灯片会被清掉，版式沿用模板的「封面 / 标题和内容」。
   - 「Pair work / Group work / Role play」这类**活动名**不会被当成一页标题（以前会单独占一页、
     页面上只有「操练」两个字）；只有标题没有内容的页会并回上一页。
4. 「输出格式」可选：
   - **PowerPoint `.pptx`**：能在 PowerPoint / WPS 里继续改，放映用这个。
   - **网页课件 `.html`**：单个文件，双击用浏览器打开就能放；`←` `→` / 空格翻页，`Home` `End` 首末页，
     `N` 显示讲稿，右下角有页码；`Ctrl+P` 一页一张能直接打成纸质讲稿；不联网、没有外链。
     投屏时按 `F11` 全屏即可（换电脑只要拷这一个文件）。

## 八、整套：一节课的东西一次做齐

周五下午备下周一那节课，往往要出四样东西。点「整套」，手上有什么就填什么，空着的跳过：

- **试卷**：选题库文件（Excel / Word / CSV），或者把题干粘在「试卷 · 或者直接粘题干」里；要答题卡、要参考答案页就勾上。
- **听写单**：点「浏览…」选班级交上来的词表（Word / Excel / CSV / txt 都行），双栏，附答案页。
- **教案**：把草稿粘进「教案 · 草稿」（课题、目标、重点、教学过程这些行），按学校表格式排。
- **课件**：把内容粘进「课件 · 内容」，格式选 .pptx 或网页 .html，也能套学校 PPT 模板。

点「一次做齐」，四件一起出，结果卡逐条写清每件做到哪儿：

> ✓ 整节课的东西都做好了｜用了 9.4 秒
> 试卷：共 2 题，合计 4 分　印前检查通过（100 分）
> 听写单：共排进 14 条，2 栏
> 教案：认出了 3 个字段、2 个教学环节
> 课件：共 4 页（PowerPoint，还能接着改）
> 共 3 页 · 这是第一页（试卷预览）

四件互不影响：**哪件没做成只报那一件**，别的照出。试卷印前检查没通过时只是不导 PDF，Word 照样给。

四栏全空点下去会被拦住，提示「至少填一样」。

## 九、文件加工

- **净化格式**：把同事转发来的、从网上下载的 Word 「洗」成能直接印的样子——拆掉超链接（文字留下）、
  去掉彩色/高亮、字体统一（默认宋体）、段落前后间距清零、删掉多余空段、**清掉备课批注**
  （批注是给自己看的，跟着文件发给学生/家长不合适；清掉的条数会在结果里说明）。
  **下划线默认保留**——英语划线题、填空横线、画出中心句都靠它，删了就看不出来；
  真要删得在选项里明确指定，结果里会提醒。
  默认**不动原文件**：净化结果另存成同目录的「原名_净化后.docx」，结果卡会告诉你副本在哪、原件没动。
  真要覆盖原件得在选项里明确要求（覆盖前会自动备份一份「原名_原件备份.docx」）。
  页眉页脚里下载站那种「免费下载 / 资源网 / www.xxx.com」推广行也会一起删掉（有校名的抬头不会动）。
- **合并多份**：每行一个文件绝对路径，按顺序拼成一份，**每份之间自动分页**，图片会一起搬过去
  （两份都有 image1.png 也不会撞坏文件），自动编号的题号跟着保留。
   「页眉页脚怎么带」三档：**沿用第一份**（默认，学校抬头只印一次、页码连续）；
   **每份保留自己的**（不同学校/年级的卷子合在一起时用——每份正文各起一节、各自带自己的抬头，页码接着往下数；
   页眉里只有图片的那种带不过来，会留空，结果里会说明）；**都不要**（只拼正文，自己再套模板）。
  批注不跟过来（合并是拼正文，批注会在结果里说明丢了几条）。
- **批量净化**：一次给一串 Word 路径（一行一个，或点「浏览…」逐个加），逐个净化，
  最后汇总「拆了多少超链接、统一了多少处字体、清了多长间距」，失败的会列出文件名和原因。
- **检查一份卷子**：不出卷，只做印前检查——纸型、方向、页边距、页码域、题号、分值、字体、残留占位符，
  逐条告诉你怎么改。给出卷前最后一道关用。
- **提取文字**：把正文和表格读成纯文字，贴在对话里继续用。

三个动作遇到「打不开的文件」（老的 `.doc`、设了密码的 docx、没下载完的文件、错当成 docx 的 PDF）会直接告诉你
该怎么处理（用 Word/WPS 另存为 .docx、先去掉密码），不会甩一句英文报错。

产物默认落在 `文档\教师助手\` 下面，按「出卷 / 课件 / 文件加工」分子目录，
文件名是「名字_年月日-时分」，不会互相覆盖。

## 十、常见问题

**点「教师助手」没反应 / 面板打不开**
先刷新一次页面（插件是启动时加载的）。还是不行就看是不是刚升级过插件——重启 DSH。

**卷子尾部贴了一大段答案，会不会印进学生卷**
不会。单独一段 `【答案】1—5 BCBDA …`（或每行一条 `1. A`）会被当成答案区收走，按题号回填到答案页；
学生卷只印题、不印这段。收了几条会在结果卡上写明。

**同一份卷子再导一次 PDF 会不会报错**
不会。同名 PDF 会被直接覆盖（结果卡写「覆盖了原来那份」），路径里的文件夹不存在会自动建。
只有真写不进去才报错——文件正在 Word 里开着、没有权限、磁盘满了，都会用中文告诉你下一步做什么。

**点了任务，面板关了，对话里却没开始做 / 报「本轮运行失败 API 密钥无效」**
插件做的是「把这件事和你们学校的规矩放进对话」，真正干活的是 DSH 的模型。
报 API 密钥 / 额度 / 网络这类错，说明模型那一头没连上，跟插件无关：去设置 → 账号配好密钥再来一次，
或者用面板底部的「直接出成品（老方式）」，那条路不经过模型。

**「体检失败：forbidden / HTTP 403」**
插件只在 DSH 自己的页面里响应，别在别的网站标签页里点它。刷新一次页面通常就好。

**「Python 就绪 · 缺 LibreOffice，PDF 导出不可用」**
这个 DSH 安装里没有内置 LibreOffice。Word/PPT 还能照常做，只是导不了 PDF。
换一个完整安装的 DSH，或用 Word/WPS 手动「另存为 PDF」。

**「这个文件打不开，它可能不是 .docx」**
老的 `.doc`、设了密码的 docx、或者没下载完的文件都打不开。用 Word/WPS 打开它，
「文件 → 另存为」选 `.docx` 再试；有密码先去密码。

**「没跑通：文件不存在」**
填的是绝对路径吗？Windows 路径里请用 `\`，或者直接从资源管理器复制（复制出来就是对的）。

**卷子上的公式**
公式目前**不做转换**。Word 里的 OMML 公式会被当普通文字保留，跨软件复制会变形，
数学卷子建议出完 Word 后自己在 Word/WPS 里补公式。

**扫描件 / 图片里的文字**
不认，没有 OCR。要提取文字请用能选中文字的 Word/PDF。

**换了学校 / 换了年级，画像会不会串**
画像只认你**这次说了什么**：这次给了纸型就用你的，没说才用记住的。想清掉重来，对助手说「忘掉我学校的设置」，
或者直接删 `%USERPROFILE%\.dsh\teacher-kit\profile.json`。

**预览和成品一样吗**
一样。逐页预览是从**导出的 PDF** 出的图，你在面板里看到的排版就是打印出来的排版。

### 0.17.0 修掉的几处（升级前值得知道）

- **8 开两栏长题干不再多印一张空白页**：以前卷头单独占第一页，现在卷头（卷名 / 分值 / 班级姓名学号）写进第一页页眉，正文直接从下面两栏开始。
- **听写单不再把中文答案印在题面上**：词表是三列（单词 / 音标 / 词义）时，只取单词那一列出题，释义留在答案页。
- **套学校模板不再带着上学期的班级**：「XX中学七年三班 英语」这种页眉会换成 `{{className}}` 占位符，出卷时填这次的班级。
- **题库没表头也不会把答案当选项**：整列长得像答案（A/B/C/D、对/错）时自动认回答案列，解析与分值也各归各位。
- **一段认不出题号的文字不再出空卷**：会停下来告诉你题号该怎么写，而不是给你一份没有题的卷子。
- **大题库组卷不再报「spawn ENAMETOOLONG」**：题干很长（超过三万字）也能传进去了。

### 0.18.0 修掉的几处（升级前值得知道）

- **套模板 + 答题卡时页脚印错总页数**：模板页脚写「共 {{pages}} 页」时，多节卷子会印「共 5 页」而 PDF 只有 4 页；现在多节时不印总页数，只留「第 N 页」。

- **卷子中间那条「【答案】1—5 ABCDA」不再吞掉后面的大题**：以前它被当成卷尾答案区起点，11 题只剩 5 题、答题卡与答案页一起缩水，印前检查还报 pass。
- **答题卡 / 答案页的第一页有页脚了**：也不再顶着正文整块卷头（卷名、满分、班级）重复印一遍。
- **套学校模板不再被默认 8 开盖掉**：模板的 270×390 竖版与页边距会保留，模板页眉的校名在第一页也看得见。
- **题库用合并单元格存材料时，第 2 套也有短文了**：以前跨行合并的材料只留在第一套。
- **教案 / 公文的表跨页后有表头、不再被撕成两半**：两张表挨着写会被 Word 当成一张表，中间现在垫了一个看不见的 1 磅空段。
- **坏输入一律说人话**：路径带看不见的控制字符、`runs` 写成一句话、输出盘符不在、图片宽度是负数——都不再回英文 internal（241 例对抗输入 0 例英文报错）。

已知限制：一份教案的板书块较大时，第 2 页可能只有板书框与作业布置（约一页留白）。板书块保证不被跨页撕开，但没有强行拉伸版面——拉伸会牺牲正常单页教案的排布。

## 十二、学校画像（越用越像你们学校）

0.15 起，助手会记住你们学校那几件每次都一样的事，**下次不再问你**：

| 记住什么 | 例子 |
| --- | --- |
| 学校与学科 | 临河区第三中学，初中七年级英语 |
| 出卷署名 | 出卷老师写「张老师」，使用班级写「七（1）班」 |
| 卷面规格 | 8 开横向两栏；页脚写法「使用班级：{{className}}　出卷老师：{{teacherName}}」 |
| 教案版式 | 表格式 / 流程版；一课时一页 |
| 课件风格 | 正文字号 28pt、16:9、学校蓝 |
| 公众号 | 语气正式；落款「临河区第三中学德育处」 |
| 公文 | 本单位全称、常打交道的承办科室 |
| 常用时长 | 90 分钟、要不要答题卡 |

**怎么记**：面板第一行点「设定我的学校」，或者干脆在对话里说一句
「我们学校是临河区第三中学，初中英语，卷子一律 8 开横向两栏，出卷老师写张老师」。
每次做完活它也会问一句「这套版式要不要记成你学校默认」，说「要」就记下了。

**它不是死模板**：画像是**兜底**——你这次说了什么就用什么，没说才用记住的。
所以同一台电脑上带两个班、两所学校也不乱；想清掉就说「忘掉我学校的设置」。

**存在哪**：`%USERPROFILE%\.dsh\teacher-kit\profile.json`，纯本地，可以自己打开改（改坏了也不影响生成，
读不出来就当没记住）。里面还有一份 `history`：能回看「这工具是怎么变成现在这样的」。

## 十三、公众号推文

说清这件事就行：**什么活动、什么时候、谁参加、想突出哪一点、要不要署名**。

- 出三样：**可粘贴的 HTML**（全部内联样式，粘进公众号编辑器不掉版式）、**审稿用 docx**，
  以及一份「哪里会被手机吃掉」的体检。
- 体检会点出来的：标题太长（手机上被截成一行）、没写摘要、整段太长、用了「全市第一」「最佳」
  「100%」这类绝对化说法、忘了落款。
- 有四种配色（学校蓝 / 暖色 / 青绿 / 黑白），来自画像或现场指定。
- **不联网、不发布、不配图、不生成二维码**——图片和发布还是你自己在公众号后台做。

## 十四、公文流转

一份办理单，按「收文 → 拟办 → 批示 → 承办 → 归档」的顺序排好：

1. **收文登记表**：来文单位、发文字号、收文日期、密级、份数、承办科室、办理期限、登记号。
2. **来文要点**：一两句话说清上级要你干什么。
3. **拟办意见**：谁牵头、怎么办、什么时候报回（单独一页，签发时好签字）。
4. **领导批示**：留给手写。
5. **承办流转单**：登记 / 拟办 / 批示 / 承办 / 归档，每步写承办部门、责任人、时限。
6. **回复稿**（可选）：主送机关顶格、正文首行缩进、落款右对齐。

送签前会提醒：要素空着、**急件却没写办理期限**、拟办意见太短、流转环节没写时限、回复稿缺主送机关或落款。
要素参照 GB/T 9704 的常用项，**红头和印章按需，不替你加盖**，也不替代单位的机要流程。

## 十五、对话式引导是怎么走的

点一件事之后：

1. 面板把你选的活写成一句「我想做这件事：……」，**连同学校画像**放进下面的话框，然后自己关掉。
2. 助手先看你缺什么：材料（题干 / 词表 / 模板 / 来文原文）**缺就点名跟你要**，不让你填一堆表。
3. 关键的选择（考哪个单元、用不用模板、要哪几种成品）用**按钮问 2–3 个**，默认值排在第一个。
4. 问清了就直接做，做完把**文件路径和预览**给你；不满意直接说「改成 A4」「加一份答案」「语气再活泼点」。
5. 最后问一句「这套版式记成你学校默认吗」。

**内容按你这次给的材料写，不套一份通用模板**——这也是它不给你“标准答案”的原因：
同样的「出试卷」，8 个人用会有 8 种结果，因为它们学校的纸型、页脚、题量、习惯都在画像里不一样。
